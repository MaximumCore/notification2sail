# notification2sail
notification2sail is an app that sends push notifications whenever there is a new entry or announcement for a regatta on the [manage2sail](https://www.manage2sail.com/) website.

## Features & Usage

### Subscribe to Regattas:
Select a regatta in the app and click *"Subscribe Regatta"* to receive notifications for it.
### Manage Subscriptions: 
In the side menu, you can view all your subscribed regattas and remove them at any time.
### Notification Settings: 
Further down in the side menu under *"Settings"*, you can select which changes trigger a notification <sub>(Details, Classes, Entries, Results, Documents)</sub>.
